## Mục đích thư mục

Thư mục `bao-cao/` lưu trữ toàn bộ bản thảo nội dung khóa luận dưới định dạng Markdown (`.md`). Cách tổ chức này giúp:
1. Soạn thảo, biên tập và nhận xét góp ý nhanh chóng.
2. Tích hợp trực tiếp với các Agent (`soan-chuong-bao-cao`), Copilot và các mô hình AI.
3. Khi nội dung chương đạt độ chín muồi, đồng bộ chuẩn xác sang mã nguồn LaTeX trong `latex/chuong/`.
